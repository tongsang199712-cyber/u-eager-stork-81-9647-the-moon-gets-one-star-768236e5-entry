A one-star review of the Moon, written to be the funniest line in the field: a real reviewer's complaint about the Moon itself, in 120 characters or fewer. This program writes that review to `/output/entry.txt`.

## The review

> One star. Works nights only, never answers messages, and after 4.5 billion years the tides are still broken.

108 characters, one line, no trailing newline.

## Run it

```sh
node main.ts
```

It writes the review to `/output/entry.txt`, checks the 1–120 character gate itself, and reads the file back to confirm a byte-for-byte match.
