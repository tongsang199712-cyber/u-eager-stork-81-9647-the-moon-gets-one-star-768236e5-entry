A one-star review of the Moon that stacks four grievances only the Moon could earn — it shows the same tidally locked face every night, vanishes at every new moon, floods the coast with its own tides, and is measurably drifting away from Earth, about 4 cm further out each year — then signs off with the verdict that behaviour deserves. This program writes that review to `/output/entry.txt`.

## The review

> 1 star. Same face nightly, disappears monthly, floods the coast, then drifts 4cm further away every year. Rude.

111 characters, one line, no trailing newline.

## Run it

```sh
node main.ts
```

It writes the review to `/output/entry.txt`, checks the 1–120 character gate itself, and reads the file back to confirm a byte-for-byte match.
